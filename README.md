# E-Mail-Analyzer---Company-Sector-Identification-Tool

## Project Description

This project is a web-based Email Analyzer that  processes a list of email addresses and extracts useful information such as domain  name, company name, domain type, and possible university identification. The system also exports the analysed data into an Excel file for further use. 

## Features

- Email text analysis using NLP
- Company sector prediction
- TF-IDF text vectorization
- Machine Learning classification
- Simple Flask web interface
- Fast and accurate predictions

## Technologies Used

- Python
- HTML
- CSS
- JavaScript

## Project Workflow

1. Input email text
2. Pre-process the text
3. Convert text using TF-IDF
4. Predict the company sector
5. Display the result

## How to run

1. Download or clone the project from GitHub.
2. Make sure Python is installed on your system.
3. Open the project folder in VS Code or any other code editor.
4. Install the required Python libraries using the requirements.txt file.
5. Run the Flask application.
6. Open the local URL shown in the terminal in your web browser.
7. Enter the email text and check the predicted company sector.
